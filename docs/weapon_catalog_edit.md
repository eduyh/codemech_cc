# CodeMech 武装・装備 オリジナル名称＆統廃合 編集シート

このファイルを直接編集し、**「新名称（記入）」** と **「統廃合・変更指示（記入）」** を書き込んでください。  
編集が終わったら「反映して」とお伝えいただければ、`src/data/parts.ts` や初期機体・ミッション・保存データ互換エイリアスまでまとめて反映します。

## 記入ルール
- **新名称（記入）**: 変更したいオリジナル名称を記入してください（空欄のまま＝現行維持、廃止する場合は空欄でも可）。
- **統廃合・変更指示（記入）**: 以下のような指示を自由に書けます。
  - `維持`（名称変更のみ／変更なし）
  - `廃止`（代替先があれば `廃止 → ○○へ置換` と書くと初期機体も自動移行できます）
  - `〇〇へ統合`（例: `lrm15 へ統合` / `性能を統合調整`）
  - `腕専用化` / `胴専用化` / `腕・胴共通化`
  - `性能調整: ...`（例: `発射数を6発にする`、`射程・熱・連装数を調整` など）
- **互換性**: 内部 ID（`ac5` など）は既存の保存機体・共有コードとの互換維持のため裏側でエイリアス対応できます（必要であれば ID 変更も可能です）。各武装の `description`（`BattleTech` 表記が残っている箇所など）も新名称に合わせて同時更新します。

## 7. 全体方針・新規武装・統廃合メモ（自由記入欄）

### 現在の実装で少しチグハグな点（整理時のご参考）
- `ac10` だけ **腕専用** で、`ac5`・`ac20` は **腕・胴共通** になっています。
- `SRM-6 ロケットランチャー` の実発射数は **4発**、`Streak SRM-4` の実発射数は **3発** になっています。
- `LRM` 系が **4段階**（5 / 10 / 15 / 20）並んでいます（例：小・中の2種や、小・中・大の3種への整理余地あり）。
- 胴用の電子戦・迎撃パッシブ装備が単体＋複合で **7種** あります。
- `medium_laser` の説明文に `BattleTech` の名称がそのまま残っています。
