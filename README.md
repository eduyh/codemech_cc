# CodeMech.py

**Code Your Pilot, Assemble Your Mech.**

環境構築ゼロ・オフライン単一 HTML 配布に対応した、人型機動兵器バトル＆AI 教育シミュレータです。

## 主な特徴

- **二層分離アーキテクチャ**
  - **上部（パイロット AI）**：【緊急】【機動】【攻撃・防御】の 3 チャンネル分離イベントカード、`hold` 維持時間・割込制御、複数戦術スタンス切替、`@pilot.*` Python 双方向変換
  - **下部（機体アセンブル＆機体 OS）**：8 部位＋前後独立装甲（頭・胴体前後・右肩前後・左肩前後・右腕・左腕・右脚・左脚）、重量/EN/コスト設計、小型 `4×4` グリッドカスタム行動マクロ
- **2.5D/3D 物理＆決定論シム（固定 30 TPS / デフォルト 30 FPS）**
  - ハイトマップ地形と障害物によるハルダウン射線遮蔽、3D 弾道、入射角による傾斜装甲・跳弾、部位破壊ペナルティ
  - 最大 **12 機** 同時対戦（2機×6チーム / 3機×4チーム / 4機×3チーム / 5〜6機×2チーム / 12機バトルロイヤル）
  - Three.js プロシージャル 3D 描画＋部位シルエット HUD
- **学内閉域ネットワーク共有＆段階的学習カリキュラム**
  - 共有コード：`CMM1-`（通常） / `CMM1B-`（対戦専用非公開） / `CMP1-`（パイロット単体） / `CMR1-`（大会ルール） / `CMC1-`（挑戦状） / `CMW1-`（完全再現リプレイ） / `CMK1-`（学習クリア証明）
  - 4 ステップ段階的学習カリキュラム（自動判定＆3D リプレイ再生）

## 開発コマンド

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# ユニットテストの実行 (Vitest)
npm test

# 型チェックと本番ビルド
npm run build

# 単一 HTML + 配布用フォルダ構成 (mechs_sample / mechs_user / mechs_import) のポータブル ZIP 生成
npm run package
```

## フォルダ構成（ポータブル配布・作業用）

- `mechs_sample/` — 付属サンプル機体（全 8 機 `.cmmech.json`）
- `mechs_user/` — 自作機体・パイロットの保管用
- `mechs_import/` — 受領機体データの保管用
- `mechs_import/replays/` — 試合リプレイの保管用
